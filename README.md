# Travel Memory Map (`travel-memory-map`)

**Contributor:** Dipannita Barua Trishna

## Problem Statement
Travelers often scatter notes, restaurant spots, ticket prices, and photos across different apps. **Travel Memory Map** provides a persistent Java archive that organizes travel experiences by country and city, supports runtime filtering and rating-based sorting, and offers both a console CLI and an interactive web map with photo uploads.

## Prerequisites
- **Java:** JDK 21
- **Build Tool:** Apache Maven 3.8+ (or IntelliJ IDEA bundled Maven)
