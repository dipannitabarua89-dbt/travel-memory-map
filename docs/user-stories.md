# User Stories & Backlog

- **US-01:** As a traveler, I want to record landmarks with architectural style, entry fee, date, and rating.
- **US-02:** As a traveler, I want to log culinary experiences with dish names, prices, and ratings.
- **US-03:** As a user, I want memories grouped under Countries and Cities with automatic average ratings.
- **US-04:** As a user, I want to filter memories by category or minimum rating and sort them by rating.
- **US-05:** As a user, I want my memories saved to a CSV file and restored automatically between runs.
- **US-06:** As a user, I want an interactive map GUI where I can click locations and attach travel photos.
